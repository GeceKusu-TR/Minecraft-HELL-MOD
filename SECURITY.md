# Güvenlik politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri aşağıdaki sürüm hattı için değerlendirilir:

| Sürüm hattı | Durum |
| --- | --- |
| `main` | Destekleniyor |
| En son kararlı yayın | Destekleniyor |
| Daha eski yayınlar | Desteklenmiyor |

## Güvenlik açığı bildirimi

Güvenlik açıklarını herkese açık issue olarak açmayın. GitHub deposunun **Security** sekmesindeki **Report a vulnerability** seçeneğiyle özel bildirim gönderin.

Özel bildirim kullanılamıyorsa, ayrıntıları herkese açık hale getirmeden önce depo sahibine GitHub üzerinden ulaşın. Bildirimde etkilenen sürümü, yeniden üretme adımlarını, etkiyi ve mümkünse düzeltme önerisini paylaşın.

Bildirimler doğrulanır, etkilenen sürümler ve düzeltme planı belirlendikten sonra uygun bir düzeltme yayınlanır. Bilgileri sorumlu açıklama süreci tamamlanmadan kamuya açmayın.
